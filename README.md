# React 다마고치 게임

기존 시력 스크리닝 앱을 제거하고, 간단한 다마고치 육성 게임으로 변경한 프로젝트입니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## 게임 규칙

- 3초마다 포만감/행복/에너지/청결 수치가 감소합니다.
- 행동 버튼(밥주기, 놀아주기, 재우기, 씻기기, 간식)으로 상태를 관리합니다.
- 두 개 이상의 핵심 수치가 0이 되면 게임 오버입니다.
- 턴이 지날 때마다 코인이 쌓이며, 간식은 5코인을 사용합니다.
